## 报告 ② · 推动中核地勘收购 · 路径方案

### 一句话结论

这件事的成败不在"矿好不好"，而在**能不能被翻译成中核自己的事**。中核地勘集团内部已存在成熟的"综合矿业"机制（"一队一所一矿"、矿业开发事业部、白土营子探采一体化、聚鑫矿业），矿权收购是被官方通稿承认的既有打法；真正卡住交易的是"非主业"与"追责"两个词。正确姿态不是说服对方"这个矿好"，而是**替对方设计一条即使失败也不追责的路**。
