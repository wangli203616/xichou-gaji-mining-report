## 一句话结论

**能不能推动成功，不取决于能不能说服谁，而取决于这宗矿权能不能先被写成一份央企投资评审会愿意签字的材料。** 当前的四个关键要素（区块边界、矿石量、永久基本农田重叠、出让方底价依据）全部停在"未确认"状态——所以主路径不是"攻关"，而是**先把不可评估的资产变成可评估的资产，再把它交给一个愿意在体系内署名的单位**。
